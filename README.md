# Homebrew-Tap von thoands

```bash
brew install --cask thoands/tap/recallnor
```

| Cask | Beschreibung |
|---|---|
| `recallnor` | [Recallnor](https://recallnor.com) – Claude-Code-Verlauf vollständig durchsuchen, Favoriten sammeln, Übergaben für neue Chats erstellen (macOS 14+) |

Aktualisieren: `brew upgrade --cask recallnor`
