# Homebrew-Tap von thoands

```bash
brew install --cask thoands/tap/recallnor
brew install --cask thoands/tap/storenor
```

| Cask | Beschreibung |
|---|---|
| `recallnor` | [Recallnor](https://recallnor.com) – Claude-Code-Verlauf vollständig durchsuchen, Favoriten sammeln, Übergaben für neue Chats erstellen (macOS 14+) |
| `storenor` | [Storenor](https://storenor.de) – App-Store-Produktseiten so anzeigen, wie sie je Gerät, Land und Sprache ausgeliefert werden (macOS 14+) |

Aktualisieren: `brew upgrade --cask recallnor` bzw. `brew upgrade --cask storenor`
